# Anzai Voice Samples

Cantonese TTS voice-selection preview samples.

Gender mapping (FLEURS): 0 = male, 1 = female.
- MALE candidates: ref/sample-20, ref/sample-427, ref/sample-748 (FLEURS gender 0)
- FEMALE candidates: ref/sample-329, ref/sample-727, ref/sample-432 (FLEURS gender 1)

- `ref-*.mp3`: reference recordings from Google FLEURS (yue_hant_hk), licensed CC-BY-4.0 (attribution: Google).
- `sample-*.mp3`: Cantonese test sentence synthesized by CosyVoice2 zero-shot voice cloning using the corresponding reference.
